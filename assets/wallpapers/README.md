# Wallpapers

Made for Stratum, in code (`numpy` + Pillow), and released with it under the same
licence. 3840 × 2160.

| | |
|---|---|
| `01-dusk` | violet into ink, a low warm glow |
| `02-signal` | the bar's mark: a ring of dots round a red dot |
| `03-dunes` | warm grey bands |
| `04-aurora` | teal and green ribbons |
| `05-graphite` | a fine dot grid lit from one corner |
| `06-bloom` | one soft coral orb |
| `07-contour` | topographic lines, dark |
| `08-paper` | the same lines, light |

The installer copies them into `~/Pictures/Wallpapers` as `stratum-*.jpg`.
